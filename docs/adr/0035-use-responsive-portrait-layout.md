# Use a responsive portrait layout

v1 牌桌 Canvas 跟随手机当前可视区域重新布局，不采用固定设计分辨率的等比缩放和黑边。敌人、战场与手牌区域按可用高度分配空间，卡牌、文字和触控区域使用尺寸上下限，内部渲染像素比最高为 `2`。最低可玩竖屏视觉视口为 `320 × 568 CSS px`；任一维度更小时显示 DOM 尺寸不足遮罩并设置 `viewport` 交互阻断原因。页面使用动态视口高度和安全区 inset，不禁止浏览器缩放。自动化覆盖 `320`、`360`、`412` 和 `480 CSS px` 宽度，以及地址栏伸缩和横竖切换，从而验证不同 Android 比例而不放大 GPU 像素负载。
