# Separate the DOM shell from the gameplay canvas

v1 UI 使用 DOM 呈现无对局、不可恢复存档、加载失败和会话失效状态，以及确认、错误与终局结算层；进行中或已结束的牌桌、卡牌、敌人、触控命中和提交事件动画统一由表现引擎绘制在一个 Canvas 中。已结束对局冻结最终牌桌并禁用 Canvas 输入，DOM 结算层展示胜负、单人评级和开始新局操作。DOM 不可视地提供 TalkBack 语义控制层，但不绘制或移动游戏对象；覆盖层打开时设置 `modal` 交互阻断原因，由统一能力门面同时限制 Canvas 与语义操作，从而避免两套游戏坐标、动画和可用性系统。
