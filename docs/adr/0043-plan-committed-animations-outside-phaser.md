# Plan committed animations outside Phaser

v1 在 Phaser 之外设置纯 UI 表现规划器，以提交前快照、有序的 `GameEvent[]` 和提交后快照作为输入，生成不可变的 `AnimationCue[]`。每条 cue 只包含提示类型、公开卡牌 ID 或数量以及时长等级，不包含像素坐标、Phaser 对象或 Tween 实例；Scene 在开始播放每条 cue 时依据当前布局解析视觉位置。Phaser Scene 只播放动画提示并在批次结束后对齐提交后快照，不直接解释领域事件或推进对局状态。映射在 TypeScript 中对已知事件保持穷尽；运行时遇到未知或无法规划的事件时跳过整个动画批次并直接呈现提交后快照。视口、方向或渲染上下文变化使当前布局失效时同样废弃整个批次，不重算部分完成的动画。这样事件映射、顺序、快进和减弱动态效果可以脱离 WebGL 单测，新增事件或重新布局也不会让已提交对局卡在旧画面。
