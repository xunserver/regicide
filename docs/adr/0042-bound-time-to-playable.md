# Bound time to playable

v1 在 Pixel 6a 级别的基准真机和最新稳定版 Google Chrome 上使用独立的 `shell-ready` 与 `game-ready` 性能标记。React DOM 外壳从页面导航开始，到会话状态和对应 DOM 控件可响应为止，冷缓存 `p95` 不超过 `1.5 秒`。恢复已有 `active` 对局时，`game-ready` 同样从页面导航开始；玩家开始或替换新局时，则从确认操作开始，排除确认前的阅读和停留时间。牌桌冷缓存 `p95` 不超过 `5 秒`，暖缓存 `p95` 不超过 `2 秒`；开始或替换新局的完成点还必须包含会话成功提交。

测试通过生产 HTTPS 构建执行，网络固定为下行 `10 Mbps`、上行 `2 Mbps`、往返延迟 `100 ms` 且不人工注入丢包；冷缓存只清除 HTTP 缓存并在计时前注入固定测试存档，暖缓存复用已经填充的 HTTP 缓存。冷、暖各执行 20 次，以 `performance.mark` 记录就绪点并要求 `p95` 达标。进行中对局以当前局面完整呈现且第一个合法玩家操作可以获得反馈为完成点，已结束对局以最终牌桌和可响应的 DOM 结算操作完整呈现为完成点。后台预取的可选插画与音效不计入完成条件。超过目标时必须优化关键加载路径，而不能用持续显示加载动画代替就绪状态。
