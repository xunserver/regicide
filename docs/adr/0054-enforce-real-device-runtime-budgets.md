# Enforce real-device runtime budgets

v1 在 Pixel 6a 基准真机和最新稳定版 Chrome 上，以固定种子的代表性选择、出牌、多卡抽取、承伤弃牌与敌人切换循环执行发布性能验收。活动阶段的 `p95` 帧间隔不得超过 `20 ms`，超过 `50 ms` 的长帧少于 `1%`；加载、页面后台和 WebGL 上下文重建区间单独统计。点击到首个视觉反馈的 `p95` 不超过 `100 ms`。按解码像素及 mipmap 计算的常驻 WebGL 纹理不超过 `96 MiB`。从预热并回收后的基线开始连续运行 30 分钟，保留 JS 堆增长不超过 `10 MiB`，结束时的帧表现相对开始时退化不超过 `10%`。无动画和触控活动时，实际渲染频率保持在 `15 ± 2 FPS`。任一指标失败都阻止发布，除非先用新的 ADR 调整预算及理由。
