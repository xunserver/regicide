# Lock player intents during committed event animation

v1 UI 在一次应用操作返回 `committed` 后，按顺序播放该结果携带的提交事件，并在动画队列清空前设置 `animation` 交互阻断原因以拒绝新的玩家意图。应用状态和自动存档仍在动画开始前完成提交；该阻断只保护表现层不会在旧画面尚未追上当前快照时继续推进规则状态，拒绝和存储失败结果不进入动画队列。普通操作的动画设计目标不超过 `1.2 秒`，包含敌人击败、揭示或胜负结算的整个批次以墙钟时间 `2.5 秒` 为硬上限；到期立即对齐提交后快照。多张抽取与弃置使用并行或短错峰表现，时长不得随卡牌数量线性增长。快进控制从 `animation` 阻断开始就同时对触控和 TalkBack 可用，玩家可以立即完成当前整组动画并按最新会话快照重绘；快进只清除 `animation` 原因，不得清除后台、模态层或其他阻断。页面进入后台时执行相同的快进，并在返回后直接呈现最新快照。系统启用减弱动态效果时取消位移、缩放、震动和粒子动画，只保留不超过 `150 毫秒` 的状态淡变与文字反馈。快进、时限和减弱动态效果只改变表现进度，不撤销事件、规则状态或触发事件回放。
