# Regicide art pack

Dark-fantasy ash & candlelight set for Phaser H5.

| File | Role |
|---|---|
| `bg_table.png` | Full-bleed table background |
| `card_back.png` | Facedown / deck back |
| `card_frame.png` | Blank face for number/ace composition |
| `royal_jack.png` / `royal_queen.png` / `royal_king.png` | Enemy & hand royals |
| `suit_*.png` | Heart / Diamond / Club / Spade pips |
| `ace_*.png` | Animal companion emblems |
| `jester.png` | Solo jester token |
| `ui_plaque.png` / `ui_button.png` | HUD chrome |

Number cards are composed at runtime: `card_frame` + suit pip + Cinzel rank.
